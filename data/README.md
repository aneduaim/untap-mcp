# UK claims rules

A copy of the [Untap UK claims rules dataset](https://untap.money/open-data/rules): every rule Untap applies to UK train Delay Repay, UK261 and EU261 flight compensation and TfL refund claims, one record per rule, with its sources, the date each was last checked and a version.

| File | What it is |
|---|---|
| `uk-claims-rules.json` | Every record, with the dataset version, licence and citation |
| `uk-claims-rules.csv` | The same records, one row each; `values_json` carries every value |
| `changelog.json` | Every change to a rule, with its date and the change in Untap's code |

The live copy is at https://untap.money/open-data/rules.json and is updated first. This folder is refreshed when the plugins are published, so it can be a few days behind.
